Op basis van je [X] contactkliks converteren 
leveranciers in [Categorie] gemiddeld ~[Z]% 
aan boekingen. Dat is een potentiele omzet van 
€[Geschatte waarde].

🏆 BENCHMARK

[X] profielweergaven per maand.

- Use "jij/je" (informal) if TPW brand is warm/friendly

## A/B Testing Recommendations

Test these variables monthly:

| Element | Option A | Option B |
|---------|----------|----------|
| Subject line | Benefit-focused ("145 views") | Curiosity ("Dit leverde je listing op") |
| CTA button | "Bekijk Dashboard" | "Bekijk Je Resultaten" |
| Social proof | Benchmark (top 10%) | Peer quote/testimonial |
| Projected value | Conservative estimate | Optimistic estimate |
| Send time | 9:00 AM | 6:00 PM |

**Winner stays, loser rotates out.**
